# Blob0 参照分析（2026-10-20）

> 参照物：https://blob0.com/zh/ 的应用截图（`browse-light/dark`、`preview-light`，
> 1180×760 原图已核对）。Blob0 = S3 系 macOS 客户端，Finder 式文件管理器语言。

## Blob0 的视觉语言（从原图逐条提取）

| # | 特征 | 截图证据 |
|---|------|----------|
| B1 | **平铺白底，无卡片**：内容区与窗口齐平，侧栏是极浅灰（亮）/ 近黑（暗），1px 分隔线 | browse-light/dark |
| B2 | **侧栏选中 = 实心蓝 pill**：饱和蓝底 + 白字（约 #0A66FF），不是淡染色 | browse-light「全部文件」 |
| B3 | **内容区顶部是 Bucket 标题块**：粗体 bucket 名 + 次行统计「5 个文件夹，6 个文件，1.60 GB」；操作按钮（⇅、新建文件夹、**实心蓝「上传」分裂按钮**）排在标题右侧 | browse-light |
| B4 | **工具栏 = 筛选/排序/搜索/视图切换**：「全部类型▾」「名称↑▾」两个描边下拉 + inset 搜索框 + **网格/列表分段切换** + 固定/刷新图标 | browse-light |
| B5 | **网格视图大图标**：文件夹用 macOS 蓝文件夹；文件用**按类型着色**的文档图标（粉=图片、黄=压缩、紫=视频、绿=音频、浅蓝=PDF/文档） | browse-light |
| B6 | **侧栏底部 = 账号卡**：头像方块 + 账号名 + endpoint + 切换 chevron；设置在其上方。账号**不在侧栏顶部** | browse-light |
| B7 | **顶部导航是应用级目的地**：仪表盘 / 全部文件 / 最近文件（我们没有仪表盘与最近文件） | browse-light |
| B8 | **预览浮层**：大卡片 = 头部（图标+文件名 / 分享、外开、下载、关闭）+ 内容嵌板（灰底里一张白文档卡）+ **底部元数据条**（类型 badge · 大小 · 修改时间 · 文件键 + 复制键按钮） | preview-light |
| B9 | **选中后标题栏右侧就地出现动作**（下载 / 移动 / 删除，删除红色） | preview-light 背景 |
| B10 | 暗色 = 内容近黑（≈#0B0B0C）、侧栏略浅（≈#151517）——**明暗关系与亮色一致**（侧栏永远比内容「凹」） | browse-dark |

## 与 CloudStorage 现状/契约的映射

| Blob0 | 我们现状 | 冲突？ |
|-------|----------|--------|
| B1 平铺 | Workbench v2 刚落了**圆角卡片**浮在 chrome 上 | ⚠️ 方向相反，二选一 |
| B2 实心蓝 pill | 「选中是淡染色，不染主色」+ `selection_differs_from_primary` 测试 | ⚠️ **契约翻转**，需改 agents.md §5.7 + 测试 |
| B3 标题块 + 统计 | 标题栏面包屑已有路径；状态条有「共 N 项」 | ✅ 可加 bucket 标题块；**统计只能按已加载条目算**（服务端分页，无全量总数），需诚实标注 |
| B4 工具栏 | 已有：上传▾/新建目录/下载/更多 + 前缀搜索 + 刷新 | ✅ 接近；分段视图切换依赖 B5 |
| B5 网格视图 + 彩色图标 | 只有列表视图；图标单色琥珀（`file_icon`）+「不按类型分色」决策 | ⚠️ 网格视图是新功能（大）；**彩色类型图标**是契约翻转（小，列表也可用） |
| B6 底部账号卡 | 账号列表在侧栏顶部，底部是传输/设置 | ⚠️ IA 调整（中）；多账号 → 卡片+切换弹层 |
| B7 仪表盘/最近文件 | 无此功能 | ❌ 超范围（新功能，非视觉） |
| B8 预览元数据条 | 预览浮层无底部元数据条 | ✅ 可加（小） |
| B9 选中即现动作 | 动作为右键菜单/工具栏常驻 | ✅ 可选增强（工具栏已常驻下载/更多） |
| B10 暗色关系 | 一致（chrome 凹、内容抬） | ✅ 已一致 |

## 建议落法

**不冲突、可直接做**（本批）：
- B3 bucket 标题块（统计按「已加载」诚实标注，或移到状态条保持唯一真相源）
- B8 预览浮层底部元数据条

**契约翻转、需拍板**（见对话中的问题）：
- B1 平铺 vs 卡片
- B2 实心蓝 pill
- B5a 彩色类型图标（列表先行）
- B3c 「上传」改实心主色按钮
- B6 账号卡移到底部

**超范围（另立项）**：
- B5b 网格视图（需要第二套条目布局 + 图标资产）
- B7 仪表盘 / 最近文件
